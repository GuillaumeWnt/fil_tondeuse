# Règles de fabrication PCB (Contraintes Hénallux / JLCPCB 2 couches)
- Isolement minimal piste-à-piste (Clearance) : 0.2 mm (8 mils)
- Largeur minimale de piste (Track Width) : 0.25 mm (10 mils)
- Diamètre minimal de perçage de via : 0.3 mm (trou) / 0.6 mm (diamètre total)
- Distance minimale cuivre-à-bord de carte : 0.5 mm
- Aucune piste sous un quartz ou une self de découpage sans plan de masse intercalé.
